# ComicCraft AI ✨ - AI Powered Comic Story Generator

An AI powered comic story generator using React + Vite and Node.js

## 🚀 Features
- AI generates comic stories from prompts
- Custom characters & scenes
- Download as images / PDF
- Modern UI with Tailwind CSS

## 🛠️ Tech Stack
- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Node.js, Express
- **AI:** OpenAI / Stability API

## 📁 Project Structure
- frontend/ - React app
- backend/ - Node.js server

## ⚙️ How to Run Locally
1. Clone repo: git clone https://github.com/varshinidec05-arch/ComicCraft-AI
2. Frontend: cd frontend -> npm install -> npm run dev
3. Backend: cd backend -> npm install -> npm start
